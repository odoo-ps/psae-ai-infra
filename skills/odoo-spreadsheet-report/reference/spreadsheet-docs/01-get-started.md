# Get Started with Odoo 19.0 Spreadsheet

Source: https://www.odoo.com/documentation/19.0/applications/productivity/spreadsheet/get_started.html

## Create a New Spreadsheet

1. Navigate to Odoo Documents and select your desired section or folder
2. Click New and choose Spreadsheet
3. Select either Blank spreadsheet or pick from available templates
4. Click Create
5. Rename by clicking "Untitled spreadsheet" at the top

**Alternative creation methods:**
- Use File → New within an open spreadsheet
- Insert data directly from another Odoo application

New spreadsheets default to the My Drive personal folder in Documents.

## Templates

All database users can access templates.

### Creating Templates
1. Open your spreadsheet
2. Click File → Save as template
3. Modify the Template Name if needed
4. Click Confirm

Once saved as a template, further changes to the open spreadsheet stay in that spreadsheet only.

### Using Templates
- Documents → New → Spreadsheet → select template → Create
- Or Documents → Configuration → Spreadsheet Templates → New spreadsheet

### Managing Templates
Documents → Configuration → Spreadsheet Templates: Copy / Edit / Delete.

## Upload Files

Import `.xlsx` or `.csv`:
1. Open Documents → destination folder
2. New → Upload
3. Select file → Open
4. Optional: Toggle "Send source file to trash"
5. Open with Odoo Spreadsheet

## Manage Spreadsheets (File menu, Editor rights)

- Make a copy
- Share (access rights)
- Download (.xlsx)
- Print
- Save as template
- Move to trash (30-day permanent delete)
- Add to dashboard
- See version history
- Settings (locale)

### Version History
- View older versions read-only
- Restore via ellipsis
- Copy older versions
- Name versions

### Regional Settings
Locale affects thousand/decimal separators, date/time format, first day of week.
Blue globe icon = spreadsheet locale differs from user profile.

### Convert to Dashboard
File → Add to dashboard → name → section → access groups → Create.
First tab of spreadsheet = front end of dashboard. Edit via Odoo Dashboards afterwards.
